# 电视遥控功能说明文档

## 📋 功能概览

本文档说明 TV 控制应用的各项功能支持情况，包括哪些功能完全支持，哪些功能需要系统权限（可能无法执行）。

---

## ✅ 完全支持的功能（无需系统权限）

以下功能在普通应用权限下即可正常工作：

### 1. **音量控制 (DP 2: volume_set)**
- **功能描述**：设置音量档位（0-100）
- **支持状态**：✅ **完全支持**
- **实现方式**：使用 `AudioManager.setStreamVolume()`
- **权限要求**：普通应用权限即可
- **说明**：
  - App 下发档位值（0-100），设备自动适配到实际最大档位
  - 如果下发值超过设备最大档位，自动设置为最大档位
  - 支持本地音量变化监听，自动上报给 App
  - 上报实际设置的档位值，让 App 知道设备的最大档位

### 2. **静音控制 (DP 3: mute)**
- **功能描述**：静音/取消静音
- **支持状态**：✅ **完全支持**
- **实现方式**：使用 `AudioManager.adjustStreamVolume()`
- **权限要求**：普通应用权限即可
- **说明**：
  - 支持本地静音状态变化监听，自动上报给 App
  - 状态同步准确

### 3. **回到主页 (DP 8: tv_home)**
- **功能描述**：返回电视主界面
- **支持状态**：✅ **完全支持**
- **实现方式**：使用 `Intent.ACTION_MAIN` + `Intent.CATEGORY_HOME`
- **权限要求**：普通应用权限即可
- **说明**：
  - 使用系统 Intent 方式，无需特殊权限
  - 执行后上报 `false`（无状态操作）

## ⚠️ 需要系统权限的功能（可能无法执行）

以下功能需要系统级权限（`INJECT_EVENTS` 或 `WRITE_SETTINGS`），普通应用无法获取，**可能无法正常工作**：

### 1. **电源开关 (DP 1: switch)**
- **功能描述**：电视开关机控制
- **支持状态**：⚠️ **需要系统权限（预留功能）**
- **实现方式**：预留接口，需要系统权限或厂商 SDK
- **权限要求**：系统级权限（普通应用无法获取）
- **说明**：
  - 当前实现为预留功能，会显示 Toast 提示
  - 上报 `false` 状态
  - **建议**：需要厂商提供系统级 API 或系统签名

### 2. **方向键控制 (DP 6: direction_control)**
- **功能描述**：上下左右方向键控制
- **支持状态**：⚠️ **需要系统权限（可能无法执行）**
- **实现方式**：使用 `Runtime.exec("input keyevent ...")`
- **权限要求**：`INJECT_EVENTS` 系统权限
- **说明**：
  - 普通应用无法获取此权限
  - 如果权限不足，会显示 Toast 提示"需要系统权限"
  - 执行后会上报方向值（枚举：up=0, down=1, left=2, right=3）
  - **建议**：需要系统签名或 root 权限

### 3. **菜单键 (DP 7: tv_menu)**
- **功能描述**：打开/关闭电视菜单
- **支持状态**：⚠️ **需要系统权限（可能无法执行）**
- **实现方式**：使用 `Runtime.exec("input keyevent KEYCODE_MENU")`
- **权限要求**：`INJECT_EVENTS` 系统权限
- **说明**：
  - 普通应用无法获取此权限
  - 如果权限不足，会显示 Toast 提示"需要系统权限"
  - **建议**：需要系统签名或 root 权限

### 4. **确认键 (DP 9: enter)**
- **功能描述**：模拟确认/OK 键
- **支持状态**：⚠️ **需要系统权限（可能无法执行）**
- **实现方式**：使用 `Runtime.exec("input keyevent KEYCODE_DPAD_CENTER")`
- **权限要求**：`INJECT_EVENTS` 系统权限
- **说明**：
  - 普通应用无法获取此权限
  - 如果权限不足，会显示 Toast 提示"需要系统权限"
  - 执行后上报 `true`
  - **建议**：需要系统签名或 root 权限

### 5. **返回键 (DP 10: back)**
- **功能描述**：模拟返回键
- **支持状态**：⚠️ **需要系统权限（可能无法执行）**
- **实现方式**：使用 `Runtime.exec("input keyevent KEYCODE_BACK")`
- **权限要求**：`INJECT_EVENTS` 系统权限
- **说明**：
  - 普通应用无法获取此权限
  - 如果权限不足，会显示 Toast 提示"需要系统权限"
  - 执行后上报 `false`（无状态操作）
  - **建议**：需要系统签名或 root 权限

## 💡 解决方案建议

### 对于需要系统权限的功能：

1. **系统签名**：
   - 如果应用可以获取系统签名，则可以正常使用所有功能
   - 需要厂商或系统集成商提供系统签名

2. **Root 权限**：
   - 如果设备已 root，可以通过 root 权限执行按键命令
   - 需要修改代码以支持 root 方式执行

3. **厂商 SDK**：
   - 部分电视厂商提供专用的控制 SDK
   - 可以集成厂商 SDK 来实现按键控制

4. **系统集成**：
   - 作为系统应用预装到设备中
   - 可以获取系统级权限

## 📝 技术说明

### 权限说明

- **普通应用权限**：应用安装后即可使用，无需特殊授权
- **系统权限**：需要系统签名或 root 权限，普通应用无法获取

### 实现方式

- **AudioManager**：用于音量控制，普通权限即可
- **Intent**：用于返回主页，普通权限即可
- **Runtime.exec()**：用于模拟按键，需要系统权限

### 状态同步

- 所有 DP 数据都会显示在 UI 上
- 支持本地状态变化监听（音量、静音）
- MQTT 上线后自动同步初始状态
- 使用 SharedPreferences 记录状态，避免重复同步
